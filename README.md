# 🏰 הטירה הקסומה של דניאל

**Daniel's Magic English Castle**

משחק הרפתקה תלת-ממדי בדפדפן, שמלמד אנגלית בסיסית לילדה בת 8 דוברת עברית: קודם דרך **שמיעה**, ואחר כך דרך **קריאה** אמיתית בשיטת הפוניקס.

---

## מה זה

דניאל מטיילת בטירה קסומה, פוגשת דמויות פנטזיה ידידותיות, ופותחת שערים על ידי השלמת משימות קצרות באנגלית. כל ההוראות בעברית, ותשעת האזורים הראשונים אינם דורשים קריאה כלל: כל משימה מתחילה בהשמעה, וכל אפשרות בחירה היא תמונה, צבע, כמות או אות.

שלושת האזורים האחרונים הם משהו אחר לגמרי. שם דניאל לומדת **לקרוא**: לפרק מילה לצלילים, לבנות אותה מאריחים, ולפענח מילה כתובה שלא שמעה קודם.

שנים עשר אזורים, 127 משימות, 124 מילים, 19 צלילים.

## מטרות לימודיות

1. **שמיעה לפני קריאה, אבל לא במקומה.** בתשעת האזורים הראשונים המילה תמיד מושמעת והטקסט באנגלית כבוי כברירת מחדל. בשלושת האחרונים הכיוון מתהפך: המילה מוצגת כתובה ודניאל מפענחת אותה בעצמה.
2. **בלי תסכול.** ארבעה יהלומי חיים בכל משימה. כשנגמרים היהלומים חוזרים לתחילת אותה משימה בלבד, עם ארבעה יהלומים חדשים ורמז חזק יותר. אף פעם לא חוזרים לתחילת המשחק, ואף פעם לא נאמרת המילה "נכשלת".
3. **רמזים מדורגים.** טעות ראשונה: מקשיבים שוב. טעות שנייה: נחשפת המשמעות בעברית. טעות שלישית: נשארות רק שתי אפשרויות.
4. **חזרה חכמה.** מילה שנטעו בה חוזרת אחרי כמה משימות אחרות, ובסוג משימה שונה, כדי שהחזרה לא תרגיש כמו עונש.
5. **בלי ציונים.** מסך ההתקדמות מראה מה נלמד וכמה כוכבים נאספו. אין אחוזי הצלחה ואין ספירת טעויות.

### סוגי המשימות

**משימות שמיעה** — בוחרים תשובה מתוך אפשרויות:

| סוג | מה קורה |
|---|---|
| שמיעה ובחירת תמונה | משמיע מילה, בוחרים בין 3 עד 4 תמונות |
| התאמת מילה לחפץ | לוחצים על רמקול, ואז על החפץ שמתאים |
| צליל ואות | משמיע צליל אות, בוחרים את האות, ואז שומעים "A is for apple" |
| בחירה בין שתי מילים | תמונה גדולה ושני רמקולים |
| ספירה | סופרים חפצים ובוחרים מספר, או שומעים מספר ובוחרים כמות |
| צבעים | שומעים שם צבע ובוחרים את הצבע |
| משפט שלם | שומעים משפט ובוחרים את הסצנה המתאימה |
| גדול וקטן | אותו עצם בשני גדלים |
| חזרה בקול | שומעים, אומרים בקול, ולוחצים "שמעתי ואמרתי" |

**משימות קריאה** — כאן כבר לא מספיק לזהות:

| סוג | מה קורה |
|---|---|
| צליל ← אות | שומעים צליל בודד, בוחרים את האות שעושה אותו |
| שרשור באוזן | שומעים c... a... t, מחברים בראש ובוחרים תמונה |
| **בניית מילה** | שומעים מילה ובונים אותה מאריחי צליל, לפי הסדר |
| **קריאה** | המילה מוצגת כתובה ולא מושמעת. מפענחים ובוחרים תמונה |

שתי האחרונות הן היחידות במשחק שאין בהן תשובות מוכנות לבחירה. בבנייה דניאל מייצרת את המילה במקום לפסול אפשרויות, ובקריאה היא חייבת לפענח, כי המילה לא נשמעת עד אחרי התשובה.

## דרישות מערכת

- **Node.js 18 ומעלה** (פותח על Node 24)
- דפדפן מודרני עם WebGL: Chrome, Edge או Firefox
- לקריינות: Chrome או Edge נותנים את התוצאה הטובה ביותר

> **הערה למחשב הנוכחי:** Node מותקן ב-`C:\Program Files\nodejs` אבל אינו ב-PATH.
> אפשר להוסיף אותו פעם אחת ב-PowerShell:
>
> ```bash
> setx PATH "$env:PATH;C:\Program Files\nodejs"
> ```
>
> או להריץ את הפקודות עם נתיב מלא, למשל `& "C:\Program Files\nodejs\npm.cmd" run dev`.

## איך מוסיפים צליל או מילה לקריאה

מנוע הצלילים יושב ב-[src/learning/phonics.ts](src/learning/phonics.ts). שם מוגדרות 19 הפונמות בשלוש קבוצות הוראה, **לא לפי סדר האלפבית**: הקבוצה הראשונה היא `s a t p i n`, כי ממנה לבד אפשר לבנות מילים אמיתיות כבר במשימה הראשונה.

**מילה חדשה לפענוח** מקבלת שדה `sounds` במאגר המילים הרגיל:

```ts
{ id: 'hat', english: 'hat', hebrew: 'כובע', category: 'sounds', difficulty: 1, emoji: '🎩', sounds: ['h', 'a', 't'] },
```

הפירוק חייב להרכיב בדיוק את האיות, ויש בדיקה עצמית שמוודאת את זה. מילה בלי `sounds` פשוט לא תופיע במשימות קריאה.

**כשמוסיפים משימת קריאה לאזור**, שווה לבחור הסחות שנבדלות בצליל אחד בלבד — `cat` מול `cap` מול `pan`. אם ההסחות רחוקות, אפשר לנחות על התשובה מהתמונה בלי לפענח כלום, והבדיקה העצמית תתפוס לפחות את המקרה שבו ההסחות באורך שונה.

**שתי מלכודות שהבדיקה תופסת בשבילך:**

1. `c` ו-`k` עושים בדיוק אותו צליל. אם שניהם מוצעים באותה שאלת "איזו אות עושה את הצליל הזה", יש לשאלה שתי תשובות נכונות.
2. אזור שאין לו `phonicsSet` לא יציג שום משימת קריאה, גם לא כמשימת חזרה. זה מכוון: ל-`red` יש פירוק לצלילים, אבל בגן הצבעים דניאל עוד לא ראתה אף אריח.

**מגבלה ידועה:** קריינות הדפדפן לא יודעת להגות פונמה בודדת, ועל אות בודדת היא אומרת את שם האות. לכן לכל צליל יש שדה `say` עם קירוב שנבחר באוזן, ועיצור עוצר כמו `t` מקבל שווא קל. המילה השלמה תמיד מושמעת מהקריינות הרגילה ולכן תמיד נכונה. אם תתווסף פעם הקלטה אמיתית, מוסיפים אותה תחת `audioKey` בדיוק כמו במילים, בלי לגעת בקוד.

## פרטיות ובטיחות

המשחק מיועד לילדה, ולכן אין בו:

- פרסומות
- קישורים לאתרים חיצוניים
- רכישות
- צ'אט
- יצירת חשבון או התחברות
- איסוף מידע אישי
- קוד אנליטיקה או מעקב
- שרת או מסד נתונים
- תוכן מפחיד, אלימות או ספירה לאחור מלחיצה

כל ההתקדמות נשמרת ב-`localStorage` של הדפדפן במחשב עצמו, תחת מפתח יחיד בשם `dmec:v1`. אם הדפדפן חוסם שמירה, המשחק ממשיך לעבוד מהזיכרון ומודיע על כך בהגדרות.

המיקרופון כבוי כברירת מחדל. אם מדליקים אותו בהגדרות, הוא משמש רק כדי לומר "שמעתי אותך", אף פעם לא מוריד יהלום ואף פעם לא חוסם התקדמות. שום הקלטה לא נשמרת ולא נשלחת לשום מקום.

## נגישות

- כפתורים בגובה 64 פיקסלים לפחות
- ניווט מלא במקלדת: Tab וחצים בין אפשרויות, Enter או רווח לבחירה, Escape ליציאה
- **אף פעם לא צבע בלבד**: תשובה נכונה מסומנת בירוק, בסימן ✓, בהגדלה ובצליל. במשימות הצבעים לכל אפשרות יש צורה שונה ושם עברי
- נעילת קלט בזמן אנימציה, כדי שלחיצה כפולה לא תיספר פעמיים
- כפתורי מגע בפינה, שמתעמעמים מאליהם ברגע שמזוהה שימוש במקלדת
- תמיכה ב-`prefers-reduced-motion`
- נבדק ברוחב 1024 על 600 ובגודל טאבלט

## פתרון תקלות

**לא שומעים כלום.** הדפדפן מרשה קול רק אחרי לחיצה. צריך ללחוץ פעם אחת על "בואי נתחיל" במסך הפתיחה. אפשר גם לבדוק בהגדרות שהמתגים דלוקים.

**ההוראות בעברית לא מוקראות.** לא מותקן קול עברי במערכת. המשחק עובד במלואו, וההוראות מוצגות בטקסט גדול. ב-Windows אפשר להוסיף קול עברי דרך Settings → Time & Language → Speech.

**מסך שחור או הודעה על תלת-ממד.** הדפדפן לא תומך ב-WebGL או שהאצת החומרה כבויה. כדאי לנסות ב-Chrome או ב-Edge מעודכנים.

**ההתקדמות לא נשמרת.** הדפדפן במצב פרטי או חוסם אחסון. מסך ההגדרות מציג על כך הודעה.
