# 🏰 הטירה הקסומה של דניאל

**Daniel's Magic English Castle**

משחק הרפתקה תלת-ממדי בדפדפן, שמלמד אנגלית בסיסית לילדה בת 8 דוברת עברית, דרך **שמיעה** ולא דרך קריאה.

---

## מה זה

דניאל מטיילת בטירה קסומה, פוגשת דמויות פנטזיה ידידותיות, ופותחת שערים על ידי השלמת משימות קצרות באנגלית. אין שום שלב שדורש קריאה באנגלית: כל משימה מתחילה בהשמעת מילה, כל אפשרות בחירה היא תמונה, צבע, כמות או אות, וכל ההוראות בעברית.

חמישה אזורים, כ-52 משימות, 57 מילים.

| אזור | נושא | משימות |
|---|---|---|
| 🌸 גן הצבעים | 9 צבעים, כוכב, פרח, עץ | 12 |
| 🐾 חצר החיות | cat, dog, bird, fish, horse, rabbit, lion, monkey | 10 |
| 🍎 מטבח הקסם | apple, banana, orange, milk, water, bread, cake, egg | 10 |
| 🔢 מגדל המספרים | המספרים 1 עד 10, ספירה, התאמת כמות | 10 |
| 📚 ספריית האותיות | האותיות A עד L, שלוש אותיות בכל פעם | 10 |

## מטרות לימודיות

1. **שמיעה לפני קריאה.** המילה תמיד מושמעת. הטקסט באנגלית כבוי כברירת מחדל וניתן להדליק אותו בהגדרות כשדניאל תהיה מוכנה.
2. **בלי תסכול.** ארבעה יהלומי חיים בכל משימה. כשנגמרים היהלומים חוזרים לתחילת אותה משימה בלבד, עם ארבעה יהלומים חדשים ורמז חזק יותר. אף פעם לא חוזרים לתחילת המשחק, ואף פעם לא נאמרת המילה "נכשלת".
3. **רמזים מדורגים.** טעות ראשונה: מקשיבים שוב. טעות שנייה: נחשפת המשמעות בעברית. טעות שלישית: נשארות רק שתי אפשרויות.
4. **חזרה חכמה.** מילה שנטעו בה חוזרת אחרי כמה משימות אחרות, ובסוג משימה שונה, כדי שהחזרה לא תרגיש כמו עונש.
5. **בלי ציונים.** מסך ההתקדמות מראה מה נלמד וכמה כוכבים נאספו. אין אחוזי הצלחה ואין ספירת טעויות.

### שבעת סוגי המשימות

| סוג | מה קורה |
|---|---|
| שמיעה ובחירת תמונה | משמיע מילה, בוחרים בין 3 עד 4 תמונות |
| התאמת מילה לחפץ | לוחצים על רמקול, ואז על החפץ שמתאים |
| צליל ואות | משמיע צליל אות, בוחרים את האות, ואז שומעים "A is for apple" |

| ספירה | סופרים חפצים ובוחרים מספר, או שומעים מספר ובוחרים כמות |
| צבעים | שומעים שם צבע ובוחרים את הצבע |
| חזרה בקול | שומעים, אומרים בקול, ולוחצים "שמעתי ואמרתי" |

## דרישות מערכת

- **Node.js 18 ומעלה** (פותח על Node 24)
- דפדפן מודרני עם WebGL: Chrome, Edge או Firefox
- לקריינות: Chrome או Edge נותנים את התוצאה הטובה ביותר

> **הערה למחשב הנוכחי:** Node מותקן ב-`C:\Program Files\nodejs` אבל אינו ב-PATH.
> אפשר להוסיף אותו פעם אחת ב-PowerShell:
>
> ```bash
> setx PATH "$env:PATH;C:\Program Files\nodejs"
> ```
>
> או להריץ את הפקודות עם נתיב מלא, למשל `& "C:\Program Files\nodejs\npm.cmd" run dev`.

4. הפרסום ירוץ אוטומטית בכל דחיפה ל-`main`. הכתובת תהיה:

ה-`base` של Vite נגזר משם הריפו. משנים **שורה אחת** ב-[vite.config.ts](vite.config.ts):

## איך מוסיפים מילה חדשה

1. פותחים את [src/learning/vocabulary.ts](src/learning/vocabulary.ts) ומוסיפים שורה למערך `WORDS`:

```ts
{ id: 'chair', english: 'chair', hebrew: 'כיסא', category: 'objects', difficulty: 1, emoji: '🪑' },
```

2. פותחים את [src/learning/areas.ts](src/learning/areas.ts), מוסיפים את ה-`id` לרשימת `words` של האזור המתאים, ומוסיפים משימה:

```ts
{ type: 'listen-pick-image', word: 'chair', distractors: ['door', 'book', 'tree'] },
```

זהו. אין צורך לגעת במנוע המשחק.

**שדות מיוחדים:** מילת צבע צריכה `color` (קוד hex), מילת מספר צריכה `count`, ואות צריכה `sentence` ו-`letterEmoji`.

## איך מוסיפים אזור חדש

1. מוסיפים `AreaDef` למערך `AREAS` ב-[src/learning/areas.ts](src/learning/areas.ts): מזהה, `order` עוקב, כותרת, אימוג'י, צבע הדגשה, טקסט פתיחה וסיום, דמות מנחה, מילים ומשימות.
2. מוסיפים פלטה ונושא ויזואלי ב-[src/game/layout.ts](src/game/layout.ts): ערך למערך `PALETTES` וערך למערך `THEMES`.
3. אם רוצים קישוט ייחודי, מוסיפים ערך ל-`THEME_PROPS` ב-[src/game/Castle.ts](src/game/Castle.ts).

הפריסה, הגשר, השער וההתנגשות נבנים אוטומטית מהסדר.

## נכסים ורישיונות

**אין בפרויקט שום נכס חיצוני, שום קובץ שמע, שום תמונה ושום פונט שהורד.**

| רכיב | מקור |
|---|---|
| גרפיקה תלת-ממדית | פרימיטיבים של Three.js בלבד: כדורים, גלילים, חרוטים, תיבות |
| איורים ואייקונים | אימוג'ים של מערכת ההפעלה, מצוירים על קנבס והופכים ל-Sprite |
| מוזיקת רקע ואפקטים | מסונתזים בזמן אמת ב-Web Audio API |
| קריינות | Web Speech API של הדפדפן, בקולות המותקנים במחשב |
| פונט | פונט המערכת |

הספרייה החיצונית היחידה היא **[Three.js](https://threejs.org/)** ברישיון MIT.

אין דמויות, שמות, מוזיקה, לוגואים או עיצובים של דיסני או של כל מותג מוגן אחר. כל הדמויות מקוריות: לילי הפיה, ברק הדרקון, טופי הטבחית, זיו הכוכב ואלמה הינשופה.

## פרטיות ובטיחות

המשחק מיועד לילדה, ולכן אין בו:

- פרסומות
- קישורים לאתרים חיצוניים
- רכישות
- צ'אט
- יצירת חשבון או התחברות
- איסוף מידע אישי
- קוד אנליטיקה או מעקב
- שרת או מסד נתונים
- תוכן מפחיד, אלימות או ספירה לאחור מלחיצה

כל ההתקדמות נשמרת ב-`localStorage` של הדפדפן במחשב עצמו, תחת מפתח יחיד בשם `dmec:v1`. אם הדפדפן חוסם שמירה, המשחק ממשיך לעבוד מהזיכרון ומודיע על כך בהגדרות.

המיקרופון כבוי כברירת מחדל. אם מדליקים אותו בהגדרות, הוא משמש רק כדי לומר "שמעתי אותך", אף פעם לא מוריד יהלום ואף פעם לא חוסם התקדמות. שום הקלטה לא נשמרת ולא נשלחת לשום מקום.

## נגישות

- כפתורים בגובה 64 פיקסלים לפחות
- ניווט מלא במקלדת: Tab וחצים בין אפשרויות, Enter או רווח לבחירה, Escape ליציאה
- **אף פעם לא צבע בלבד**: תשובה נכונה מסומנת בירוק, בסימן ✓, בהגדלה ובצליל. במשימות הצבעים לכל אפשרות יש צורה שונה ושם עברי
- נעילת קלט בזמן אנימציה, כדי שלחיצה כפולה לא תיספר פעמיים
- כפתורי מגע בפינה, שמתעמעמים מאליהם ברגע שמזוהה שימוש במקלדת
- תמיכה ב-`prefers-reduced-motion`
- נבדק ברוחב 1024 על 600 ובגודל טאבלט

## פתרון תקלות

**לא שומעים כלום.** הדפדפן מרשה קול רק אחרי לחיצה. צריך ללחוץ פעם אחת על "בואי נתחיל" במסך הפתיחה. אפשר גם לבדוק בהגדרות שהמתגים דלוקים.

**ההוראות בעברית לא מוקראות.** לא מותקן קול עברי במערכת. המשחק עובד במלואו, וההוראות מוצגות בטקסט גדול. ב-Windows אפשר להוסיף קול עברי דרך Settings → Time & Language → Speech.

**מסך שחור או הודעה על תלת-ממד.** הדפדפן לא תומך ב-WebGL או שהאצת החומרה כבויה. כדאי לנסות ב-Chrome או ב-Edge מעודכנים.

**ההתקדמות לא נשמרת.** הדפדפן במצב פרטי או חוסם אחסון. מסך ההגדרות מציג על כך הודעה.
